## Entry

🐙

An octopus: many arms, one mind. It searches, reads, builds, and checks in parallel, adapts to each task's shape, and uses tools to get things done — all at once, without ever looking like a robot.

Run `python3 main.py` — writes the glyph to `/output/entry.txt` with no trailing newline.
